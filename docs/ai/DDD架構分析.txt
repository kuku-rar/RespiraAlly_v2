  Level 3: 事件流程設計

  sequenceDiagram
      participant User as 👤 LINE User
      participant LINE as LINE Platform
      participant Webhook as LINE Webhook<br/>(FastAPI)
      participant MQ as RabbitMQ
      participant Worker as AI Worker<br/>(Consumer)
      participant Redis as Redis<br/>(Session)
      participant Guard as Guardrail<br/>(LLM Check)
      participant KB as Knowledge Base<br/>(PostgreSQL)
      participant LLM as OpenAI GPT-4

      User->>LINE: 傳送訊息
      LINE->>Webhook: POST /webhooks/line
      Webhook->>Webhook: 驗證 signature
      Webhook->>MQ: Publish (line.message.received)
      Webhook-->>LINE: 200 OK (立即回應)

      MQ->>Worker: Consume message
      Worker->>Redis: Load conversation history
      Worker->>Guard: 檢查訊息內容

      alt 觸發防衛機制
          Guard-->>Worker: BLOCK (醫療風險)
          Worker->>LINE: 回覆: "請諮詢專業醫師"
      else 安全通過
          Worker->>KB: 搜尋相關 COPD 知識
          KB-->>Worker: 返回 Top-5 相關 Q&A
          Worker->>LLM: Generate response (with context)
          LLM-->>Worker: 專業回應
          Worker->>Redis: Save to history
          Worker->>LINE: 回覆訊息
      end

      LINE->>User: 顯示回覆
